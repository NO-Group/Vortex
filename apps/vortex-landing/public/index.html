Vendor lock-in

Everything you need, nothing you don't

Vortex absorbs the best capabilities from four platforms — so you never have to leave.

🔐

Authentication

Email/password, magic links, password reset, OAuth (Google, GitHub, GitLab, Discord, Apple, Microsoft, Twitter, Facebook, OIDC), JWT with custom claims, admin user management.

🗄️

Database

Real PostgreSQL with a dynamic query builder, raw SQL, filters, OR-groups, JSONB, and embeds. No magic chaining — explicit, typed, safe.

⚡

Realtime

Durable WebSocket subscriptions with reconnect replay. Table changes, room broadcasts, and presence tracking. The event you missed is the event you get.

📦

Storage

Buckets, uploads, downloads, presigned URLs, public buckets, and S3-compatible storage (AWS, R2, MinIO). Built-in image transforms — Cloudinary parity.

🖼️

Image Transforms

URL-based transforms: resize, crop, format, quality, grayscale, sepia, rotate, flip. Powered by sharp with on-disk caching. Cloudinary-compatible parameters.

🔧

Functions

Deploy serverless functions with the full Vortex SDK. Wall-clock budget, pause/resume, and context-aware invocation. Cloudflare Workers parity.

🔔

Push Notifications

Web Push (VAPID) — works in browsers with zero setup. APNs for iOS. FCM HTTP v1 for Android. Device registration, history, stats, and admin broadcast.

🌐

Edge Cache

ETag generation, conditional GET (304), Cache-Control headers, auto-invalidation on writes, and cache statistics. Cloudflare CDN parity, in-process.

🛡️

Row Policies

Compiled row-level security — policies compile to SQL and run once, not per row. WITH CHECK for writes. The guardrail Supabase doesn't have.

📊

Query Governance

Every query is EXPLAINed before execution. Cost ceiling rejects expensive queries. Slow query logging to the audit table. Safety built in.

📦

Apps Hosting

Deploy static web apps to /apps/<name>/ with SPA routing. One-click showcase deploy. Vortex carries your apps — not just your data.

🏗️

Multi-Node

Redis bridge connects multiple Vortex engines into one realtime fabric. Load-balance across instances. Scale horizontally without code changes.

Start in 5 minutes

Install the SDK, connect, and build. No credit card required.

# Install npm install @vortex/client # Build your first app import { VortexClient } from '@vortex/client' const vortex = new VortexClient({ url: 'https://vortex.example.com' }) // Sign up const session = await vortex.auth.signup({ email, password }) // Create a table await vortex.database.createTable('notes', [ { name: 'title', type: 'text', required: true }, { name: 'body', type: 'text' }, ]) // Insert data await vortex.database.create('notes', { title: 'Hello Vortex', body: 'My first note', owner_id: session.user.id }) // Realtime subscription vortex.realtime.subscribe('table:notes') vortex.realtime.onTableChange((event) => renderNotes(event.rows))
